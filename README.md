# Глоссарий терминов ВКР

Веб-приложение для визуализации и работы с глоссарием терминов выпускной квалификационной работы на тему **"Исследование производительности серверных веб-фреймворков и библиотек на основе Node.js"**.

**Демо:** [https://tatarjesus.github.io/glossary-itmo/](https://tatarjesus.github.io/glossary-itmo/)

## Описание проекта

Интерактивное веб-приложение для изучения терминологии в области серверной разработки на Node.js.

### Возможности

- Визуализация связей между терминами в виде интерактивного графа
- Фильтрация по 7 категориям
- Полнотекстовый поиск
- Просмотр определений и источников
- Навигация по связанным терминам

## Локальная разработка

### Требования

- Node.js 18+

### Запуск

```bash
git clone https://github.com/TatarJesus/glossary-itmo.git
cd glossary-itmo/frontend
npm install
npm run dev
```

Приложение будет доступно на `http://localhost:3000`

### Сборка

```bash
npm run build
```
