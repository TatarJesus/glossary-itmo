## Описание проекта

Приложение предоставляет:
- **Web API** для доступа к глоссарию терминов
- **Визуальный интерфейс** с семантическим графом (MindMap)
- **Поиск и фильтрация** терминов по категориям
- **Интерактивную навигацию** по связям между терминами

### Возможности

- Просмотр всех терминов с определениями
- Визуализация связей между терминами в виде графа
- Фильтрация по 7 категориям
- Полнотекстовый поиск
- Просмотр источников определений
- Навигация по связанным терминам

## Быстрый старт

### Требования

- Node.js 18+ (для локальной разработки)
- Docker и Docker Compose (для контейнеризации)

### Локальная разработка

1. **Клонирование репозитория:**
   ```bash
   git clone <repository-url>
   cd production-practice
   ```

2. **Запуск Backend:**
   ```bash
   cd backend
   npm install
   npm run dev
   ```
   Backend будет доступен на `http://localhost:3001`

3. **Запуск Frontend (в отдельном терминале):**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
   Frontend будет доступен на `http://localhost:3000`

## Развёртывание с Docker

### Сборка и запуск

```bash
# Сборка и запуск всех сервисов
docker-compose up --build

# Запуск в фоновом режиме
docker-compose up --build -d
```

### Доступ к приложению

После запуска приложение доступно по адресам:

| Сервис | URL | Описание |
|--------|-----|----------|
| Frontend | http://localhost:80 | Веб-интерфейс |
| Backend API | http://localhost:3001/api | REST API |
| Health Check | http://localhost:3001/api/health | Проверка состояния |

### Остановка

```bash
# Остановка сервисов
docker-compose down

# Остановка с удалением образов
docker-compose down --rmi all
```

### Просмотр логов

```bash
# Все сервисы
docker-compose logs -f

# Только backend
docker-compose logs -f backend

# Только frontend
docker-compose logs -f frontend
```

## API документация

### Endpoints

#### GET /api/health
Проверка состояния сервера.

**Ответ:**
```json
{
  "status": "ok",
  "timestamp": "2026-01-08T10:00:00.000Z"
}
```

#### GET /api/metadata
Метаданные глоссария.

**Ответ:**
```json
{
  "title": "Глоссарий терминов ВКР",
  "topic": "Исследование производительности...",
  "author": "Зиганшин Станислав Эдуардович",
  "version": "1.0.0",
  "lastUpdated": "2026-01-08",
  "totalTerms": 50,
  "totalCategories": 7
}
```

#### GET /api/categories
Список категорий терминов.

**Ответ:**
```json
[
  {
    "id": "nodejs-core",
    "name": "Ядро Node.js",
    "description": "Основные концепции и компоненты платформы Node.js"
  }
]
```

#### GET /api/terms
Список всех терминов.

**Query параметры:**
- `category` — фильтр по категории (например, `?category=nodejs-core`)
- `search` — поиск по термину и определению (например, `?search=fastify`)

**Ответ:**
```json
[
  {
    "id": "fastify",
    "term": "Fastify",
    "definition": "Высокопроизводительный веб-фреймворк...",
    "category": "frameworks",
    "relatedTerms": ["nodejs", "json-schema"],
    "sources": [
      {
        "title": "Fastify Documentation",
        "url": "https://www.fastify.io/docs/latest/"
      }
    ]
  }
]
```

#### GET /api/terms/:id
Получение термина по ID.

**Пример:** `GET /api/terms/fastify`

#### GET /api/graph
Данные для визуализации графа (формат Cytoscape.js).

**Ответ:**
```json
{
  "nodes": [
    {
      "data": {
        "id": "fastify",
        "label": "Fastify",
        "category": "frameworks",
        "definition": "..."
      }
    }
  ],
  "edges": [
    {
      "data": {
        "id": "fastify-nodejs",
        "source": "fastify",
        "target": "nodejs"
      }
    }
  ]
}
```

## Обоснование выбора технологий

### Формат контейнеризации: Docker

**Причины выбора:**
1. **Широкое распространение** — Docker является стандартом де-факто в индустрии
2. **Кроссплатформенность** — работает на Windows, Linux, macOS
3. **Экосистема** — Docker Hub, Docker Compose, интеграция с CI/CD
4. **Лёгкость освоения** — обширная документация и сообщество

**Отечественные альтернативы:**

| Решение | Описание | Особенности |
|---------|----------|-------------|
| **Podman** | Совместим с Docker, не требует демона | Поддерживается в РЕД ОС, Astra Linux |
| **containerd** | Контейнерный рантайм | Используется в Kubernetes |
| **Deckhouse** | Kubernetes-платформа от Флант | Российская разработка для enterprise |
| **SberCloud Container Service** | Managed Kubernetes | Облачное решение от Сбера |

Docker был выбран как наиболее универсальное решение, совместимое со всеми отечественными Linux-дистрибутивами (Astra Linux, РЕД ОС, ALT Linux).

### Fastify vs другие фреймворки

Fastify выбран по следующим причинам:
- **Производительность** — один из самых быстрых Node.js фреймворков
- **JSON Schema** — встроенная валидация и оптимизация сериализации
- **Плагинная архитектура** — модульность и инкапсуляция
- **Соответствие теме ВКР** — исследование производительности фреймворков

### Cytoscape.js для визуализации

- **Производительность** — эффективная работа с большими графами
- **Гибкость** — множество встроенных layouts
- **Интерактивность** — богатые возможности взаимодействия
- **Документация** — отличная документация и примеры
